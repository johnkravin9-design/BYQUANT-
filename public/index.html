What this is

ByQuant scans Bybit Spot markets, computes EMA9/EMA21, RSI14, OBV and ATR14 on confirmed candles, and emits BUY-only signals — it does not place orders or promise returns.

This page is the API gateway that receives signals, persists them, and serves reads to the ByQuant mobile client.

GET /health Gateway and database liveness check.
GET /api/signals Active signals, optionally filtered by symbol.
POST /api/signals/webhook Authenticated ingest from the market-data engine.
ByQuant API Gateway Signals are informational only and are not investment advice.
